# Talk with Your Dataset

Talk with Your Dataset is a Streamlit app that enables users to upload their own CSV datasets and interact with the data through natural language queries. Powered by AI, the app translates user questions into dynamic data analysis and visualizations without requiring any coding skills. This makes exploring, summarizing, and gaining insights from data fast, intuitive, and accessible to non-technical users.

## Tech Stack

- Python 3.x  
- Streamlit  
- Pandas  
- NumPy  

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   
2. Create and activate a virtual environment:

On Windows:
python -m venv venv
venv\Scripts\activate

On macOS/Linux:
python -m venv venv
source venv/bin/activate

3. Install dependencies:

pip install -r requirements.txt

4. Run the app:

streamlit run app.py

Usage:
Upload your own dataset (CSV format recommended).
Interact with your data using natural language queries.
Explore insights, summaries, and visualizations dynamically.

Notes:
No datasets are included in this repository. You must provide your own.
The app currently supports CSV file uploads only.
